# Review of the work so far — 2026-11-11

Scope: `playground-template` (13 commits) and `playground-portal` (16 commits, live at
`https://playground-portal-bay.vercel.app`). Method: read all portal code, the template's schema,
validator, build, widget host and agent docs; ran the template's lint, tests and both builds;
probed the live site without creating a job.

## Verdict

| Part | State | Summary |
| --- | --- | --- |
| Template | **Good, keep** | Tests (37) and lint pass. The DIS course rebuilt from JSON matches the original page text exactly (`0 pages differ (18 compared)`). A few real defects, listed below. |
| Agent guide | **Thin** | 115 lines in total. Enough for the one proof lecture, not enough for a weak agent to produce a rich course. |

The portal was built by skipping queue items 3–8. That is why it has no generator behind it.
The fix is not to patch the portal's renderer but to connect it to the template.

## What is fine

- No API key or token in either repository's history; `.env*` is ignored in both.
- Template: strict schemas, error codes with fix sentences, namespaced storage and cache, Markdown safety tests, optional exam/expected pages all work as designed.
- Portal: the key is read only on the server; uploaded sources are deleted after generation; Blob store is private; CI passes.

## Gap to the goal

Counted blocks: the hand-built DIS course has 830 blocks of 14 kinds (89 tables, 71 recall sets,
55 figures, 38 worked examples, 34 practice sets, 25 widgets). The portal's output for one PDF is
11 prose blocks. Closing this gap is the purpose of the next iteration.
